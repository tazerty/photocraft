# Evora build (patch E9): display overlay catalog. Applied to every string the UI shows through
# the translation lookups (tr, tr_ctx, tr_id, trn), English included, after the language catalog.
# It renames third-party product terms at display time only: command ids, catalog keys, the engine
# crates, the control channel and saved files keep the upstream wording.
#
# Columns, separated by a TAB:  kind <TAB> language <TAB> from [<TAB> to]
#   kind      exact   the whole displayed string equals `from`: it becomes `to`
#             sub     every occurrence of `from` inside the displayed string becomes `to`
#             drop    the word `from` is removed with the space next to it (no `to` column)
#   language  a catalog code (fr, zh-hans, ...), `en`, or * for every language
# Exact rules are tried first (the language's, then *); sub and drop rules then apply in file
# order, the language's and the * ones alike. Lines starting with # and blank lines are ignored.
#
# Sensitive terms checked by the CI gate after this overlay: Lumetri, Lightroom, Acrobat, Premiere
# (and "Premiere Pro Compatible"), Adobe, Cycore. Only "Adobe" occurs in this repository.
